## 6. Portfolio Website Technical Architecture

The portfolio itself is built as a production-grade single-page application (SPA):

- **Build Tooling:** Vite 5.3 + TypeScript 5.2.
- **Framework:** React 18.2 with React Router DOM v6.
- **Styling:** Tailwind CSS 3.4 with custom dark color scheme (`#050816` primary, `#100d25` secondary, `#151030` tertiary, `#915EFF` purple accent, `#00cea8` teal accent).
- **Animation:** Framer Motion for scroll reveals, transitions, and hover effects.
- **Accessibility:**
  - WCAG-compliant tab navigation with dual color + bottom underline indicators (`border-b-2`).
  - Semantic `<search>` landmark with invisible accessible search labels.
  - Stretched single-link card pattern (`after:absolute after:inset-0`) to eliminate duplicate screen reader tab stops.
  - Above-the-fold image priority with `fetchpriority="high"` and lazy-loading reserved for below-the-fold assets.
- **Routes:**
  - `/` — Homepage featuring Hero, Services Grid, Skills Marquee (TechTicker), Selected Flagship Work, Career Experience, and Contact Form.
  - `/projects` — Searchable and filterable showcase of all 20 projects with category tabs (`All`, `Web Apps`, `Mobile Apps`, `Automation & APIs`).
  - `/projects/:id` — Dynamic project case study page with full overview, high-resolution screenshot switcher, live and store links, and next/previous project navigation.
- **Key Source Code Files:**
  - `src/constants/index.ts` — Single source of truth for personal data, services, experiences, and all 20 projects.
  - `src/assets/index.ts` — Central asset manifest managing all optimized screenshots and SVG icons.
  - `src/pages/ProjectsPage.tsx` — Project gallery with category filter state and debounced search.
  - `src/pages/ProjectDetailsPage.tsx` — Dynamic deep-dive project detail view.
